## 3. The System — หน้าต่างทั้งหมด (ตอนนี้อยู่ใน `dev/minaria_system`)

หลัก: server สร้าง JSON แล้วส่ง `SysNet.openWindow(player, kind, json)` หรือ `SysNet.notice(player, json)`; client วาดสไตล์เดียวกัน
(กระจกกรมท่า ขอบฟ้าที่หายใจ ลายทอง อัญมณีมุม แสงกวาดหัว ฝุ่นแสง เปิดแบบซูม+เสียงระฆัง) · ปุ่ม **I** = STATUS หรือ APPRAISE ถ้าเล็งสิ่งมีชีวิตใน 8 บล็อก

| หน้า | kind / คำสั่ง | ข้อมูลมาจาก | สถานะ |
|---|---|---|---|
| STATUS | `status` · `/system status` | `minaria_system.js` (องก์ เลือด มานา กระเป๋าเงิน กฎหมาย ที่ยืน) | ดูในเกมแล้ว |
| REPUTATION | `reputation` | factions + ตระกูล (`MINARIA_C.CFR_STANDING`) | ดูในเกมแล้ว |
| BOSSES | `bosses` | เช็กลิสต์ตามองก์ + โมเดลบอสหมุน/ซูมได้ | ดูในเกมแล้ว |
| QUESTS | ในหน้า STATUS | FTB Quests ฝั่ง client (`QuestsPage`, ไม่บังคับ) | ดูในเกมแล้ว |
| CONTRACTS | `list` · `/system contracts` | `minaria_realms` `Contracts.java` อ่านบอนตี้ Bountiful ในกระเป๋า | ดูในเกมแล้ว |
| RETINUE | `list` · `/system retinue` | `minaria_court` `Retinue.java` (SavedData) | ดูในเกมแล้ว (มีชีวิต + Fallen) · Dismiss ยังไม่ได้ลอง |
| CHRONICLE | `chronicle` | ฉายา + บันทึกรายวันของทุก NOTICE | ดูในเกมแล้ว |
| REALM | `realm` · `/realm` | `confluence_world.js` + ตารางรัฐ, ซูม 1–8 ลากได้ | ดูในเกมแล้ว |
| APPRAISE | `appraise` · `/system appraise <id>` | ระดับภัย สถานะ ใครสนใจ | ดูในเกมแล้ว |
| dialog | `dialog` | ธนาคาร Lodge โบสถ์ กิลด์ (server จัดปุ่ม) | ดูในเกมแล้ว |
| NOTICE | `SysNet.notice` | ป้ายเด้ง "Entered", ชื่อเสียงขยับ, CONTRACTS | ดูในเกมแล้ว |

แท็บ (ลำดับ): STATUS · REPUTATION · BOSSES · QUESTS · CONTRACTS · RETINUE · CHRONICLE · REALM
(CODEX ถูกเอาออกชั่วคราวเพราะที่ไม่พอ จะกลับมาเมื่อมีเศษ lore) · หน้าต่าง STATUS/list กว้าง 470

**window kind `list`** (ใหม่, `ListScreen.java`) ม้อดไหนก็ส่งได้:
`{"tab","name","heading","note","empty","rows":[{"title","hex","right","icon","lines":[{"text","done","icon"}],"foot"}]}`
**API สำหรับม้อดอื่น:** `SystemApi.openWindow / notice` (`registerWindow` ถูกตัดออกตอน audit เพราะยังไม่มีม้อดไหนใช้ · เพิ่มกลับเมื่อม้อดต้องการหน้าจอของตัวเอง)

- **ส่งคำสั่งโดยไม่กดอะไรในเกม:** `python dev/console.py "คำสั่ง" "คำสั่ง2" --shot <png> --wait 3`
  (เขียน `kubejs/system_test/console.json` แล้ว **รอจน log มี `CONSOLE <id>` ครบทุกคำสั่ง** ก่อนชุดถัดไป — server ที่กำลังสร้าง chunk จะข้ามไฟล์ ถ้าส่งเร็วเกินคำสั่งหาย)
- ถ่ายภาพ: `powershell -ExecutionPolicy Bypass -File dev/screen_shot.ps1 -Out <png>` (**ต้องมี `-ExecutionPolicy Bypass`** ไม่งั้นโดนบล็อกเงียบ)
- ทดสอบหน้าต่างครบชุด: `echo {"run": true} > kubejs/system_test/run.json` แล้วเปิดโลกทดสอบ (`system_test.js` เขียน step ลง `step.json`)
- บอร์ดที่ไกล: `forceload add x z` แล้ว `setblock x 300 z bountiful:bountyboard` แล้ว `realms board x 300 z` (log บอก decree ที่ได้)
- `spreadplayers` ไปที่ไกลล้มเหลวบ่อยในโลกทดสอบ ใช้ forceload แทน
