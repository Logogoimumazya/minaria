- **Quark + Zeta, Integrated Cataclysm, Block Factory's Bosses, Fantasy Armor** — เพิ่งเข้ามาในแพ็ก (ไม่ใช่ผมใส่) Quark เป็นม้อดใหญ่ที่เพิ่มของเยอะ ต้องปิดฟีเจอร์ที่ไม่เข้าธีม บอสของ Block Factory ต้องผ่านกฎ bible ข้อ 5 ก่อน (ประเภทและองก์)

- **Alex's Mobs, Aquamirae, Tide** — สัตว์และปลาเยอะ เข้ากับโลกได้ แต่ต้องเช็กว่าไม่ทับกับสัตว์ของ Confluence
- **Create + ม้อดพ่วง** — ตามข้อ 1: เหลือเฉพาะที่เป็นของหอจดหมายเหตุ
- **Connector + ม้อด Fabric** (item-interactions, smoothskies, และอีกหลายตัว) — ทำงานได้ แต่เพิ่มความเสี่ยงพังทุกครั้งที่อัปเดต และบางตัวไม่มีบน CurseForge

## 3. แจกผ่าน CurseForge — แยกเป็นม้อดทีละชิ้น

### 3.1 ข้อจำกัดที่ต้องรู้ (ต้องตรวจกฎปัจจุบันของ CurseForge ก่อนลงมือ)

- modpack บน CurseForge คือ manifest ที่ชี้ไปยังไฟล์ของ **ม้อดที่อยู่บน CurseForge** และ `overrides/` สำหรับ config, script, resource pack
  jar ที่ไม่ได้อยู่บน CurseForge ใส่ใน overrides ไม่ได้ตามกฎทั่วไป
- **ตรวจจากแพ็กตอนนี้:** jar 346 ตัว แอป CurseForge จัดการ 325 ตัว **ไม่ได้จัดการ 21 ตัว:**
  - **ของเราเอง 7 ตัว:** minaria_court, minaria_perf, valarian_compat, mca_emf_bridge, mca_ragdoll_fix, mob_combat_sync, WesterosBlocks ฉบับพอร์ต
  - **ของคนอื่น 14 ตัว:** BOMD, Connector, DynamicTreesPlus, JER, dungeons-and-taverns, fape_compat, grassiergrass, grim-kingdoms, improved-village-placement, item-interactions, roadweaver, shulkerboxtooltip, sound-physics, voicechat
  - ต้องหาไฟล์บน CurseForge ให้ตัวของคนอื่นทุกตัว ไม่งั้นต้องตัดออก
  - ของเราเองต้องขึ้นเป็นโปรเจกต์บน CurseForge
- **WesterosBlocks ฉบับพอร์ต** เป็น jar ของคนอื่นที่เราแก้ ต้องดูใบอนุญาตของ WesterosBlocks ก่อนว่าให้แจกฉบับแก้ไหม ถ้าไม่ได้ต้องทำเป็น addon ที่พึ่งตัวจริง
- ม้อดทุกตัวในแพ็กต้องเปิดสิทธิ์ให้ใช้ใน modpack ตามที่ผู้สร้างตั้งไว้บน CurseForge

### 3.2 แยกระบบเป็นม้อด

ตอนนี้ระบบกระจายอยู่ใน KubeJS (confluence_world, minaria_system, economy, law, factions, acts, sites) กับ minaria_court
การแยกเป็นม้อด Java ทำให้ (1) ติดตั้งจาก CurseForge ได้ (2) ใช้กับแพ็กอื่นได้ (3) เร็วและเสถียรกว่าสคริปต์ (4) ไม่ต้องพึ่ง KubeJS
**หลัก:** แต่ละม้อดอ่านข้อมูลจาก datapack/config ไม่ฝังเนื้อหาของ Minaria ลงโค้ด เนื้อหา (รัฐ ตระกูล บอส ราคา) อยู่ในแพ็ก

| ม้อด (ชื่อชั่วคราว) | มาจาก | ทำอะไร | พึ่ง | ใช้กับแพ็กอื่นได้ไหม |
|---|---|---|---|---|
| **Minaria System** (ห้องสมุด UI) | `SystemWindow`, `SystemDialog`, `NoticeOverlay`, packet หน้าต่าง | กรอบหน้าต่างแบบ isekai, ป้ายเด้ง, หน้าต่างที่ server กำหนดด้วย JSON, API ให้ม้อดอื่นเปิดหน้าต่าง | Forge | ได้ |
| **Minaria Realms** | `confluence_world.js` (realms, standing, caravan, garrison, arsenal) + Realm Ledger | แผนที่การเมืองจาก datapack (รัฐ ตระกูล ความสัมพันธ์ ตาราง), standing, คาราวาน, ทหารประจำเมือง | System, (Valarian Conquest ไม่บังคับ) | ได้ ถ้าให้ datapack กำหนดแผนที่ |
| **Minaria Coin** | `minaria_economy.js` | ธนาคาร ค่าผ่านประตู คลังรัฐ ภาษีตลาด คนประจำอาคาร | System, Realms, (Confluence ไม่บังคับ: ตั้งเหรียญได้) | ได้ |
| **Minaria Court** | `minaria_court` (มีแล้ว) | Valarian Conquest ↔ MCA, ปุ่มบนหน้าจอ MCA | MCA, Valarian Conquest | ได้ |
| **Minaria Standing** | `minaria_factions.js`, `minaria_law.js`, `minaria_acts.js` | ฝ่ายห้าฝ่าย กฎเวท องก์ ฉายา บันทึก | System, (Iron's, MCA Crime ไม่บังคับ) | ได้ ถ้าฝ่ายกำหนดจาก datapack |
| **Minaria Bestiary** | BOSSES ใน `minaria_system.js` | เช็กลิสต์บอสจาก datapack (องก์ ที่อยู่ ผล) | System | ได้ |
| **Minaria Perf** | มีแล้ว | แก้ worldgen ช้า, แก้ Tide/OpalLight | Forge | ได้ |
| **แพ็ก Minaria** | ทั้งหมดข้างบน + config + FTB Quests + KubeJS ส่วนที่เป็นของแพ็กเท่านั้น | เรื่อง องก์ บาลานซ์ รายชื่อม้อด | — | — |

KubeJS ยังอยู่ในแพ็ก แต่เหลือแค่งานปรับของแพ็กนี้ (สูตร บาลานซ์ ทดสอบ) ไม่ใช่ที่อยู่ของระบบ

### 3.3 โลก — ปัญหาใหญ่ที่สุด

เซฟทวีป **5.0 GB** (region 1,052 ไฟล์) ใหญ่เกินกว่าจะใส่ใน modpack

| ทาง | ข้อดี | ข้อเสีย |
|---|---|---|
| **A. ม้อด `minaria_world`** สร้างทวีปและเมืองตอนเล่น จาก heightmap และแบบเมืองที่อัดมากับม้อด | แจกผ่าน CurseForge ได้ทั้งหมด, ไฟล์เล็ก, ผู้เล่นได้โลกใหม่ทุกครั้ง | งานใหญ่ที่สุด: ต้องย้าย pipeline Python (ภูมิประเทศ แม่น้ำ เมือง KL) ไปเป็น worldgen ของเกม · ช้าตอนสร้าง chunk |
| B. แจกโลกแยก (โปรเจกต์ World บน CurseForge หรือที่อื่น) | ได้โลกตามที่สร้างทุกบล็อก, ทำได้ทันที | ต้องตรวจเพดานขนาดไฟล์ของ CurseForge · ผู้เล่นต้องติดตั้งสองขั้น |
| C. โลกแบบย่อ | ใส่ในแพ็กได้ | เสียสิ่งที่ทำให้ Minaria ต่าง |

**ข้อเสนอ:** ทาง B ก่อน (ตรวจเพดานไฟล์, ถ้าไม่พอแบ่งเป็นหลายไฟล์หรือโฮสต์นอก) แล้วค่อยวางแผน A เป็นเวอร์ชันถัดไป

## 5. ลำดับงานที่เสนอ

2. **ตรวจม้อด** (ข้อ 2) → `MOD_ROSTER.md` · หาไฟล์ CurseForge ให้ม้อด 14 ตัวที่ไม่ได้มาจาก CurseForge

5. **แพ็กรุ่นทดสอบ** บน CurseForge (private/unlisted) + โลกตามทาง B
