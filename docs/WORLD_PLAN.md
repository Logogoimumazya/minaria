# แผนสร้างโลก Minaria — ทวีปขนาดยักษ์

> ตัดสินใจแล้ว (2026-09-24): **ผสม** — สร้างทวีปเอง + วาง schematic สำเร็จรูปเป็นเมืองหลวง · **16,384 × 16,384 บล็อก** ·
> **เล่นกันเองในกลุ่ม** (ใช้ของที่อนุญาตแค่ส่วนตัวได้ แต่ห้ามแจกต่อ — อย่า push ไฟล์พวกนั้นขึ้น repo)
> ระบบเกม (เควส ฝ่าย บาลานซ์) พักไว้จนกว่าโลกจะเสร็จ
> อ้างอิง lore: [`MINARIA_BIBLE.md`](MINARIA_BIBLE.md) §2.2 (แผ่นดินยึดสมอ / ดินแดนสะท้อน), §4 (อาณาจักรและฝ่าย)

## 0. ข้อเท็จจริงที่กำหนดทั้งแผน

- **chunk ที่สร้างไว้แล้วจะไม่ถูกสร้างซ้ำ** — โครงสร้างจากม้อด (Valarian, CTOV, lukis capitals, ถ้ำ Confluence) และมอน/NPC ที่มากับโครงสร้าง
  **ไม่เกิดเอง** ในพื้นที่ทวีป ทุกอย่างในทวีปต้องวางอย่างตั้งใจ
- **นอกขอบทวีป เกมยังสร้างโลกสุ่มตามปกติ** = ดินแดนสะท้อนใน lore ใช้ระบบถนน/เมืองสุ่มเดิมได้
- **`/place structure <id> <pos>`** (1.20) วางโครงสร้างของม้อดลงตรงพิกัดในโลกที่มีอยู่แล้วได้ — ใช้ของที่แพ็กมีอยู่แล้วทั้งหมด
- ดิสก์: C: เหลือ ~19 GB — **งานโลกทั้งหมดอยู่บน D: (ว่าง ~200 GB)**
- ประสิทธิภาพ (docs/PERFORMANCE.md): สร้าง chunk ใหม่ยังช้า — ทวีปต้อง **pre-gen ครบก่อนเล่น**

## 1. ท่อการผลิต (pipeline)

```
[W1] Azgaar FMG ──► heightmap + biomes + อาณาจักร/เมือง/ถนน/แม่น้ำ (JSON)
        │
[W2] ตารางแปล lore ──► รัฐใน FMG = อาณาจักรใน bible, เมือง = ระดับเมืองหลวง/นคร/หมู่บ้าน
        │
[W3] WorldPainter (สคริปต์) ──► ภูมิประเทศ + ไบโอม (รวมไบโอมม้อด) ──► D:\Minaria\world
        │
[W4] วางถิ่นฐาน (สคริปต์) ──► เมืองหลวง = schematic สำเร็จรูป · นคร/หมู่บ้าน = /place structure ของม้อด
        │
[W5] ถนน (สคริปต์) ──► เส้นทางจาก FMG วาดเป็นถนนตามพื้นผิว
        │
[W6] ประชากร ──► NPC MCA + ทหาร Valarian ต่ออาณาจักร (ใช้สคริปต์ merge/garrison ที่มีอยู่)
        │
[W7] ข้อมูลการเมือง ──► kingdoms.json ขับ /realm /standing และระบบฝ่าย (แทนการสุ่มตาม hash พิกัด)
        │
[W8] pre-gen ทั้งทวีป (Chunky + Distant Horizons) ──► เซฟพร้อมเล่น / ย้ายขึ้นเซิร์ฟเวอร์กลุ่ม
```

### W1 — ออกแบบทวีปใน Azgaar's Fantasy Map Generator
- เว็บ https://azgaar.github.io/Fantasy-Map-Generator/ ฟรี ทำงานในเบราว์เซอร์ ไม่ต้องติดตั้ง
- **ขั้นนี้เป็นงานสร้างสรรค์ของเจ้าของโลก** — สุ่มจนได้รูปทวีปที่ชอบ แล้วแก้ชื่อ/เส้นแบ่งอาณาจักรได้ในหน้าเว็บ
- ตั้งค่าเป้าหมาย: ทวีปหลักหนึ่งผืน · รัฐ 5–7 · เมือง (burgs) ~60–120 · มีทะเลในกับเกาะรอบนอกได้
- Export ที่ต้องได้: **`.map`** (ไฟล์งาน เก็บไว้แก้ต่อ) · **heightmap PNG** · **JSON (Full)** — มีรัฐ เมืองพร้อมพิกัด ถนน แม่น้ำ ไบโอม ศาสนา วัฒนธรรม
- ผมเขียนตัวอ่าน JSON แปลงพิกัดแผนที่ → พิกัดบล็อก (ขนาดแผนที่ → 16,384 บล็อก)

### W2 — ตารางแปล lore (FMG → bible)
| FMG | Minaria |
|---|---|
| รัฐ (state) | อาณาจักร: วาลาเรีย (ศักดินา) · สหพันธ์ออรัม (นครไอน้ำ) · จักรวรรดิออสทรัม (อาณาจักรที่กำลังตาย) · แดนเสรี + ป่าของเผ่าผู้เหลื่อม |
| เมืองหลวงของรัฐ | เมืองหลวง = **schematic สำเร็จรูป** (จุดเดียวที่ใช้ของสำเร็จรูป) |
| burg ขนาดใหญ่ | นคร = `lukis_grand_capitals` / เมือง CTOV ขนาดใหญ่ |
| burg ขนาดเล็ก | หมู่บ้าน = CTOV / Integrated Villages / Valarian castle ชายแดน |
| ศาสนา | ศาสนจักรแห่งแสงเดียว (มนุษย์) · ลัทธิบูชาบรรพกาล (เผ่าผู้เหลื่อม) |
| จุดพิเศษ | ที่นั่งของหอจดหมายเหตุ, วิหารใหญ่ของศาสนจักร, ป่าศักดิ์สิทธิ์, ซากเมืองจากยุครุ่งโรจน์ (Alex's Caves toxic caves ฯลฯ) |

### W3 — WorldPainter
- ติดตั้งจาก https://www.worldpainter.net (ฟรี, Java) — รองรับ **สคริปต์ (`wpscript`)** จึงทำซ้ำได้อัตโนมัติ
- สคริปต์: นำเข้า heightmap → ปรับสเกลเป็น 16,384 · ระดับน้ำทะเล · ภูเขาสูงสุด ~y 300 · แม่น้ำจาก FMG ·
  ระบายไบโอมตาม FMG โดยแปลงเป็นไบโอมของแพ็ก (vanilla + Confluence/Terralith-style ตามที่มีจริง — ต้องทำตารางแปล) · export ไป **D:**
- ขอบทวีป: ทะเลรอบทวีป → เกิน 16,384 ให้เกมสร้างต่อเอง (ดินแดนสะท้อน)
- **ข้อควรระวัง:** Tectonic เปลี่ยนภูมิประเทศเฉพาะ chunk ที่เกมสร้าง — ในทวีปจะเป็นภูมิประเทศจาก WorldPainter; ต้องเกลี่ยรอยต่อที่ขอบ

### W4 — วางถิ่นฐาน
- เมืองหลวง 5–7 แห่ง: **schematic สำเร็จรูป** — วางด้วย WorldEdit/Litematica ตอนสร้างโลก (ติดตั้งเฉพาะตอนสร้าง ไม่ต้องอยู่ในแพ็กเล่น)
  ต้องหา schematic เมืองยุคกลาง/สตีมพังค์ขนาดใหญ่ที่อนุญาตใช้ส่วนตัว — **รายการที่ต้องให้เจ้าของโลกเลือก**
- นครและหมู่บ้าน: สคริปต์สร้าง `.mcfunction` จาก JSON → `/place structure <id> x y z` ต่อ burg (ปรับ y ตามพื้น)
- ป้อมชายแดน: `valarian_conquest` castle ตามแนวพรมแดนรัฐ

### W5 — ถนน
- FMG มีเส้นทาง (routes) ระหว่างเมือง → สคริปต์เดินตามเส้น วางถนน 3–5 บล็อกตามพื้นผิว (ทางหลวง/ทางดิน ตามระดับถนน) สะพานเมื่อข้ามน้ำ
- ไม่ใช้ RoadWeaver ในทวีป (มันทำงานตอนเกมสร้าง chunk) — เก็บไว้ใช้ในดินแดนสะท้อน

### W6 — ประชากร
- NPC MCA และทหาร Valarian: ทดลองก่อนว่าสคริปต์ `valarian_mca_merge.js` / garrison ที่มีอยู่ทำงานกับโครงสร้างที่ `/place` หรือไม่
- ตั้งชื่อ ตำแหน่ง ฝ่าย ให้ NPC ตาม `kingdoms.json`

### W7 — ข้อมูลการเมือง
- `kingdoms.json` (จาก FMG + ตาราง W2) กลายเป็นแหล่งความจริงเดียว: พรมแดน เมืองหลวง ความสัมพันธ์ ศาสนา
- `confluence_world.js` ตอนนี้แบ่งอาณาเขตด้วย hash ของพิกัด — ในทวีปต้องเปลี่ยนไปอ่านจากแผนที่

### W8 — pre-gen และส่งมอบ
- Chunky ทั้ง 16,384² (~1 ล้าน chunk) บน D: — ประเมินหลายชั่วโมงถึงข้ามคืน (วัดจริงก่อน)
- Distant Horizons สร้าง LOD ทั้งทวีปเพื่อมองไกล
- เล่นในกลุ่ม: เซฟนี้ย้ายขึ้นเซิร์ฟเวอร์กลุ่ม (ต้องตัดสินใจเรื่องเซิร์ฟเวอร์ภายหลัง)

## 4. W3 — สิ่งที่สร้างแล้ว และข้อเท็จจริงที่ตรวจจาก jar ของ WorldPainter 2.27.1

ท่อการผลิต: `terrain.py` (ทีละไทล์ 4096² = 8×8 region) → `wp_export.js` (wpscript) → `build_world.py` รวม region
ไปไว้ที่ `D:\Minaria\world\minaria\region` · เครื่องมืออยู่ที่ `D:\Minaria\tools\` (WorldPainter ตรวจ sha256 แล้ว, Azgaar source)

| เรื่อง | ทำอย่างไร | ตรวจแล้ว |
|---|---|---|
| ความสูง | เมตรจริงจากโมเดล → `Y = 63 + 235·(m/2600)^0.9` + ridged noise บนเขา + domain warp ที่ชายฝั่ง | ที่ราบ y 64–80 เขา 150–300 |
| แม่น้ำ | แม่น้ำ Azgaar ที่ discharge ≥ 120 จำนวน 274 สาย กว้าง ∝ Q^0.38 ลึก ∝ Q^0.2 ระดับน้ำไม่สูงขึ้นตามทางไหล ส่วนที่สูงกว่าทะเลใช้ `setWaterLevelAt` | ทดสอบที่กล่องรอบ Wound |
| ไบโอม | อุณหภูมิตามโมเดลของ Azgaar (6.5 °C/km) + ความชื้นจากฝนของ Azgaar → ตาราง Whittaker (`biomes.py`) ใช้ vanilla + Nature's Spirit 50 ไบโอม | ชื่อ `natures_spirit:*` ถูกเขียนลง chunk ตรงตัว (`BiomeUtils.findBiomeName`) |
| ต้นไม้ แร่ หญ้า | chunk ถูกเขียนที่ status `liquid_carvers` (`Dimension.setPopulate(true)`) เกมจึงรันขั้น features เอง เช่น Dynamic Trees และแร่ของแพ็ก | ตรวจ NBT แล้ว: ทั้ง 1024 chunk เป็น `liquid_carvers` |
| แร่ของ WorldPainter | ปิด (`setChance(material, 0)`) ไม่อย่างนั้นแร่จะซ้ำ | ตรวจแล้ว: ไม่มี ore ใน palette |
| ถ้ำ | ถ้ำ noise ของเกมถูกสร้างก่อนขั้นที่ส่งต่อมา ทวีปจึงไม่มีถ้ำเอง → ใช้ชั้น Caves / Caverns / Chasms ของ WorldPainter | มี glow lichen และเห็ดในถ้ำ |
| รูปแบบ chunk | platform `org.pepsoft.anvil.1.19` (1.19–1.20.4) เขียน DataVersion 2860 เกมจะอัปเกรดตอนโหลด | **ต้องทดสอบในเกม** |

**ทดสอบในเกม:** save `saves/Minaria W3 test` (region รอบ Wound, level.dat จาก Forge world จริง, spawn บนเกาะกลางทะเลสาบ, creative)
สิ่งที่ต้องดู: โหลดได้ไม่ crash · ต้นไม้ของ Nature's Spirit / Dynamic Trees ขึ้นตามไบโอม · แร่มี · แม่น้ำไม่รั่ว · ถ้ำ

**ยังค้าง:** รอยต่อกับโลกสุ่มที่ขอบ (ทะเลลึกของเราชนกับพื้นดินที่เกมสร้างนอก ±8192) · level.dat ของโลกจริงควรสร้างจากเกม
แล้วค่อยวาง region ของทวีปลงไป · ถ้าอยากได้พื้นผิวตามกฎของไบโอม (surface rules) และถ้ำแบบ carver ของเกม
ต้องทดลองแก้ status เป็น `noise` ซึ่งเสี่ยงกว่า

**ผลทดสอบในเกม (2026-09-24):** โหลดโลกได้ · ไม่มี chunk เสีย (ตรวจ 1,050,056 chunk) · WesterosBlocks ครบ 4,211 บล็อก · King's Landing แสดงผลครบ
ข้อควรรู้: (1) Minecraft 1.20 ไม่ยอมเปิดโลกที่อยู่ผ่าน junction/symlink จึงต้องคัดลอก save ไว้ใน `saves/` จริง (4.5 GB)
(2) ม้อด quantumchunks ทำ server crash เมื่อเปิดโลกเป็นรอบที่สองใน session เดียว (`CpuMonitor` RejectedExecutionException) ต้องแก้แยก
(3) SimpleBackups สำรองโลกนี้ครั้งละ 2.4 GB ลง C: ซึ่งเหลือพื้นที่น้อย
