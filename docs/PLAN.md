### 4.3 T3 — เมืองท่า (29 แห่ง: นคร 4, เมือง 8, หมู่บ้าน 17)

ตัวสร้างใหม่ `harbour.py` (หรือขั้นใน `town.py`) : หาแนวชายฝั่งหน้าเมือง → กำแพงท่า (quay) → สะพานไม้ยื่น + `cleat` →
โกดังริมท่า → ร้านปลา (`fish_display`, `angling_table`) → ประภาคารที่แหลม (นครและเมือง) → เรือจอด (entity, ถ้าม้อดเรือมี)
ขนาดท่าตามขั้นเมือง · ต้องรับชิ้นริมน้ำของ KL กลับมาเฉพาะในเขตท่า · QA ใหม่: ท่าต่อกับถนนในเมือง น้ำหน้าท่าลึกพอให้เรือเข้า

### 4.4 T4 — ถนนที่ใช้งานได้จริง (W5)

- **โครงข่ายมีลำดับชั้น:** ทางหลวงระหว่างเมืองหลวงและนคร (กว้าง 5–7 ปูหิน) · ทางเมือง (3–5 กรวด) · ทางหมู่บ้าน (2–3 ดิน)
  เส้นทางตั้งต้นจาก routes ของ Azgaar แล้วเดินด้วย `route()` ใน `country.py` (MCP ตามความชัน) ที่มีอยู่แล้ว
- **สะพาน** ทุกจุดข้ามแม่น้ำ แบบตามขั้นถนนและความกว้างน้ำ · ด่านที่ข้ามพรมแดน · ป้ายบอกทางพร้อมระยะ (CITY_PLAN 8.9) · โรงเตี๊ยมริมทาง
- **ต่อกับถนนประตูเมือง** ที่มีอยู่ (outworks) ไม่สร้างซ้อน
- **"ใช้งานได้จริง" แปลว่า** (เป็นเกณฑ์ QA): ถิ่นฐานทุกแห่งต่อถึงกันทางถนน · ชันไม่เกิน 1 ใน 3 · ไม่มีขั้นสูงเกิน 1 บล็อก ·
  ม้าและเกวียนผ่านได้ (กว้าง ≥ 3 ไม่มีสิ่งกีดขวาง) · เวลาเดินระหว่างเมืองหลวงวัดได้และเขียนลงเอกสาร

### 4.5 T5 — ตรวจ jigsaw ให้แน่ใจว่าไม่มีบั๊ก

"jigsaw" ของเราคือตัวสร้างเมือง Python (TOWN_JIGSAW) ไม่ใช่ jigsaw ของเกม · QA ตอนนี้ตรวจแค่ 5 อย่าง ไม่พอจะรับรองว่าไม่บั๊ก

**QA ชุดใหม่ที่ต้องเพิ่ม** (ทุกข้อเป็นตัวเลข ต้องเป็นศูนย์):

| ตรวจ | จับอะไร |
|---|---|
| `door_blocked` | ประตูที่ไม่มีทางเดินถึงจากถนน หรือเปิดชนกำแพง/บล็อก |
| `unreachable_civic` | อาคารสาธารณะที่เดินจากประตูเมืองไปไม่ถึง (flood fill บนช่องเดินได้) |
| `cut_piece` | ชิ้นที่ถูกตัดหรือทับกัน (เทียบบล็อกที่วางกับต้นฉบับ) |
| `roof_hole` | ห้องที่ฝนตกถึงพื้น |
| `dark_spawn` | จุดในกำแพงเมืองที่มืดพอให้มอนเกิด |
| `street_steps`, `floating_parts` | มีอยู่แล้ว แต่ **ต้องแก้ที่ต้นเหตุ** ให้ 24 เมืองเป็นศูนย์ ไม่ใช่กวาดทิ้งทีละจุด |
| `repeat_piece` | ชิ้นเดียวกันซ้ำเกินกำหนดในรัศมีที่มองเห็นได้ |
| `road_link` | ถิ่นฐานที่ไม่ต่อกับโครงข่ายถนน (หลัง T4) |

**ขั้นตอน:** เขียนการตรวจ → รันทั้ง 116 แห่ง (สาย A) → ภาพรวม `summary` + ภาพจุดผิด → แก้ที่ตัวสร้าง → บิลด์ใหม่เฉพาะเมืองที่เปลี่ยน → ทัวร์อัตโนมัติจากจุดที่ QA ชี้
**ม้อด jigsaw ของเกม** (หมู่บ้าน Valarian/CTOV/grim ที่จะใช้ในดินแดนสะท้อน) ตรวจแยกในเฟส 5 พร้อม echoes

### 4.6 T6 — ประชากร (W6)

ออกแบบก่อนลงมือ: บ้านไหนมีคนกี่คน อาชีพอะไร (ผูกกับอาคารและจุดทำงาน) ทหารประจำเมืองต่อขั้นเมือง ขุนนางในปราสาท
แล้วค่อยวางด้วย `/court_staff` แบบเดียวกับ G6 · ต้องวัดผลต่อ FPS ก่อนวางทั้งทวีป (PERFORMANCE.md)
ระบบที่รอเรื่องนี้: การแต่งตั้งราชา/ลอร์ด, อาชีพ, คู่หู

### 4.7 ลำดับทำในเฟส 2

1. เครื่องมือเร่งงาน (ข้อ 2) + QA ชุดใหม่ (T5) → รู้ขนาดปัญหาจริงก่อนสร้างของใหม่
2. แก้ต้นเหตุ street_steps/floating → ทุกเมืองเดิมเป็นศูนย์
3. หาแบบเมืองหลวงและชุดวัฒนธรรม (T1, ขนานกับข้อ 1–2 เพราะเป็นสาย B/C)
4. ทำเมืองหลวงทีละเมืองจนผู้ใช้รับ แล้วค่อยใช้ชุดวัฒนธรรมกับขั้นล่าง (T2) · **หนึ่งเมืองผ่านก่อนบิลด์ทั้งหมด** (memory user-quality-bar)
5. ท่าเรือ (T3) → ถนนและสะพาน (T4) → ประชากร (T6)
6. ติดตั้งลงเซฟ (สำรองก่อนเสมอ) → ทัวร์ในเกมรอบเดียว
