## 4. ต้นเหตุที่หาเจอ (อย่าหาซ้ำ)
- portlib `PortEnvironment.registryAccess()` ไม่มีโลก → `ClientRegistryLayer.createRegistryAccess()` freeze registry จริง (EF เรียก getDefaultInstance ทุกไอเทมตอนโหลด config) → `minaria_perf/PortlibRegistryAccessMixin`
- tag วน portlib (forge:→c:) กับ Connector (c:→forge:) 143 ตัวพัง → แพ็กหลักรอดเพราะ **lmft**
- ดาบทุกเล่มท่าเดียว: ไม่มี `data/<ns>/capabilities/weapons/*.json` → EF เดาจาก `item_keyword`/คลาส · มี weapon type 76 แบบให้ใช้
- projectile Confluence: `GameClientEvents.clientTick$Post` → `SwordProjectileInputHandler` อ่านปุ่มโจมตี แต่ EF ยึดปุ่ม
- 131 ไอเทมมีการใช้ปุ่มขวาแต่ได้ท่าที่มีการ์ด (Epic Knights 113, Cataclysm 7)
- ถือของผิดที่: แก้ด้วย `assets/<ns>/item_skins/<item>.json` (transforms + trail)
- เครื่องประดับ: EF `CuriosCompat` bake ได้เฉพาะ `ICurioRenderer.HumanoidRender` · terra_curio/Artifacts เป็นแบบอื่น → fallback แข็งติด Root
