# Vertical slice ตะวันออก — ชิ้นแรกที่เล่นแล้วรู้สึกถึงแกนความจริงครบวง

เขียน 2026-09-28 จากการสัมภาษณ์ producer 3 รอบ · อ้างอิง [`TRUTH_SPINE.md`](TRUTH_SPINE.md), [`PLAN.md`](PLAN.md),
[`GAMEPLAY.md`](GAMEPLAY.md) ข้อ 4, [`SLICE_ACT0.md`](SLICE_ACT0.md)

**ทำไมต้องมี slice:** ตอนนี้มีชิ้นส่วนเยอะ (ทวีป เมือง The System บอส Epic Fight) แต่ยังไม่มีช่วงไหนที่เล่นแล้วรู้สึกถึงแกน
"ปะติดปะต่อความจริง" ครบวง slice นี้พิสูจน์แกนในพื้นที่เล็กก่อนขยายทั้งทวีป ถ้าคนที่ไม่รู้ lore เล่นแล้วไม่ขนลุก ต้องแก้แกนก่อน ไม่ใช่สร้างเพิ่ม

## 3. ด่านย่อยและเกณฑ์ผ่าน

| ด่าน | ทำอะไร | ผ่านเมื่อ | สาย |
|---|---|---|---|
| **S1 กระดาษ** | บทจังหวะทุกข้อ · บทพูดพยาน (ร่างไทย → อังกฤษในเกม) · บทฉากความทรงจำ · สตอรีบอร์ด System เพี้ยน · ข้อความเศษม่าน · หน้าเลือกดันเจี้ยนใหม่ · แผนที่เส้นทาง | คุณอ่านรับทุกข้อในหน้าเดียว | B + C |
| **S2 โครง** | ทำกลไกในโลกทดสอบแยก หน้าตายังหยาบ: เศษม่านและดรอป · ขีดทิศบน REALM · บทสนทนา MCA ตามเงื่อนไข · นักแสดง MCA ยืนนิ่ง · หน้าต่างเพี้ยน · ตัวจับเหตุการณ์ | เดินครบเส้นทางด้วยคำสั่งใน 20 นาที ทุกเงื่อนไขทำงาน ไม่มี error ใน log | A + B + D |
| **S3 จริง** | ลงทวีป: ห้องความทรงจำใต้ Dragonstone · ชนบทเสื่อม · ดันเจี้ยนใหม่ · วางพยาน · ประตูผนึก · บาลานซ์บอสกับ Epic Fight | ทัวร์อัตโนมัติผ่านทุกจุด · QA ของเมืองในเส้นทางเป็นศูนย์ · คุณเดินเองแล้วรับ | A + D + C |
| **S4 ทดสอบ** | สร้างโลก slice ใหม่ · เพื่อนเล่นแบบไม่รู้อะไร · จดเวลา จุดหลง จุดเบื่อ | เพื่อนเล่นจบโดยไม่หลงเกิน 10 นาทีติด · เล่าได้เองว่า "เคยมีคนแบบเรามาก่อน จักรวรรดิซ่อนเขาไว้ และ System ผิดปกติ" · อยากเล่นต่อ | C + D |

**กฎ:** ผ่าน S1 ก่อนเขียนโค้ด · ผ่าน S2 ก่อนแตะเซฟทวีป · ทุกด่านมีภาพหรือบันทึกเป็นหลักฐาน

## 4. สิ่งที่ต้องทำใหม่ (ข้อยกเว้นของ slice)

| ของ | ทำที่ไหน | หมายเหตุ |
|---|---|---|
| เศษม่าน (Veil Shard) | KubeJS item + loot ของบอส | ข้อความในไอเทมเป็นข้อมูล ไม่ฝังโค้ด |
| ขีดทิศบน REALM | ข้อมูลหน้าต่าง realm ของ minaria_system | ใช้กรอบที่มีอยู่ |
| หน้าต่างเพี้ยน | minaria_system (kind ใหม่หรือ flag บน window เดิม) | ข้อเดียวที่เป็น Java · ทำให้ใช้ซ้ำได้ตลอดเกม |
| เศษความทรงจำ + CODEX | KubeJS item · หน้า CODEX ยังไม่ทำ (เก็บใน CHRONICLE ไปก่อน) | CODEX เต็มรอเฟส 5 |
| บทสนทนาพยาน | ไฟล์บทสนทนา MCA (mcaconversations) | ⚠ Saint's Dragons อ่านไฟล์นี้แล้ว error อยู่ ต้องแก้ก่อน |
| นักแสดง MCA | `/court_staff` + Stay | ⚠ ทหารที่ตั้ง NoAI จมพื้นภายใต้ EF (EPIC_FIGHT 5.7) ใช้ Stay แทน |
| ห้องความทรงจำ ชนบทเสื่อม ประตูผนึก | Python worldgen (`stamp`/`country`) | ห้องบิลด์ในโลก D: ก่อน แล้วติดตั้งลงเซฟ |
| โลก slice ใหม่ | สคริปต์ตัด region + world border | ต้องยืนยันความหมายของ "ทำใหม่" |

## 5. ดันเจี้ยนใหม่ฝั่งตะวันออก — วิธีค้น (งาน S1)

เกณฑ์: Forge 1.20.1 · ใส่ modpack ได้ · สู้ได้ดีกับ Epic Fight · บอสผ่านกฎ bible ข้อ 5 + TRUTH_SPINE (เป็นหลักฐานของอะไร) ·
วางลงทวีปได้ (`/place structure` หรือบิลด์เอง) · ไม่ลากม้อดใหญ่เข้ามา
ตัวเลือกธีมที่เข้ากับตะวันออก: ป้อม Broken Aegis (ทหารที่ทิ้งป้อม) · รังใน Corruption · ท่าคนขนของที่สะพานแผ่นดิน
**ข้อจำกัด:** เครือข่ายของ cloud session นี้เข้า CurseForge/Modrinth ไม่ได้ ต้องเปิด network หรือให้ Claude บนเครื่องอ่าน jar แล้วส่งผลมา
