# แกนความจริง — ชิ้นส่วนทุกชิ้นของ Minaria หมุนรอบอะไร

เขียน 2026-09-28 จากการสัมภาษณ์ 4 รอบ (16 คำถาม) · อ้างอิง [`MINARIA_BIBLE.md`](MINARIA_BIBLE.md) ข้อ 6,
[`CATACLYSM.md`](CATACLYSM.md) ข้อ 4, [`BLUEPRINT.md`](BLUEPRINT.md) ข้อ 5–6, [`PLAN.md`](PLAN.md)

ปัญหาที่เอกสารนี้แก้: ระบบ ม้อด เมือง และบอสถูกสร้างทีละชิ้น แต่ละชิ้นดี แต่ยังไม่มีอะไรบอกว่าชิ้นไหนต่อกับชิ้นไหน
เอกสารนี้กำหนด**แกนเดียว** ให้ทุกชิ้นต้องตอบได้ว่ารับใช้แกนนี้อย่างไร ชิ้นที่ตอบไม่ได้ให้ลดลงหรือตัดออก

> **สถานะ:** คำตอบในข้อ 1 คือคำตัดสินของผู้ใช้ · ข้อ 3 เป็นต้นไปคือ**ร่างที่ผมเสนอ** ตามคำตอบนั้น ต้องให้ผู้ใช้อ่านรับก่อน
> ตามกฎ PLAN ข้อ 7 เอกสารนี้ไม่ล็อกกลไก (ตัวเลข ความตาย เศรษฐกิจ) กลไกยังล็อกในเฟส 4 แต่เฟส 1–4 ใช้เอกสารนี้เป็นเข็มทิศ

## 1. คำตอบของผู้ใช้ (ห้ามถามซ้ำ)

| เรื่อง | ตัดสิน |
|---|---|
| **ความรู้สึกเดียวที่เป็นแกน** | **ปะติดปะต่อความจริง** (Soulslike): ผู้เล่นค่อยๆ รู้ว่าตัวเองกำลังถูกพาไปทำลายโลก ทุกระบบคือเบาะแส |
| ชั่วโมงแรก | **เปิดกว้างตั้งแต่แรก** คำแนะนำสั้นๆ แล้วไปไหนก็ได้ |

| ยอมให้เบาลงเป็นฉากประกอบ | **การเมืองและสงคราม · อาชีพและเศรษฐกิจ · คู่หูและความสัมพันธ์** |

| กันหลงลำดับบอส | **อ่านออกจากโลก** แบบ Elden Ring: ไปได้ทุกที่ System บอกระดับอันตราย |
| เมือง 116 แห่ง | **ที่เก็บเบาะแสและพยาน** |
| ออกนอกทวีป | **ม่านบางทีละชั้น** วงที่ไปได้ขยายตามบอสที่ล้ม |

| ความทรงจำเป็นของใคร | **ผู้หลุดมาคนละยุค** |

**ประโยคเดียวของเกม:** ผู้มาจากต่างโลกล่าบอสทีละตัวเพื่อกลับบ้าน ทุกตัวที่ล้มคือทั้งก้าวต่อไปและหลักฐานอีกชิ้น
ว่าเขากำลังเดินตามรอยเท้าของคนที่มาก่อน ซึ่งทุกคนจบลงด้วยการกลายเป็นกำแพง

## 2. หลักห้าข้อที่ใช้ตัดสินทุกชิ้น

1. **ทุกบอสคือหลักฐาน** ฆ่าแล้วได้ของ (ความก้าวหน้า) และได้ชิ้นความจริง (ความทรงจำ หรือเบาะแสว่าบรรพกาลตัวไหนอยู่ทิศไหน)
2. **ไม่มีใครเล่าความจริงครบ** ทุกฝ่ายรู้บางส่วนและบิดตามผลประโยชน์ ผู้เล่นเทียบคำพูดเอง
3. **โลกบอกลำดับ ไม่ใช่กำแพงล่องหน** ระดับอันตรายอ่านได้จาก System ระยะ และทิศ ยกเว้นม่านที่บางลงตามบอส
4. **เมืองคือห้องสมุดของพยาน** เมืองหลวงถือชิ้นใหญ่ เมืองและหมู่บ้านถือชิ้นเล็ก
5. **The System เป็นตัวละคร** ไม่ใช่แค่ UI มันเปลี่ยนน้ำเสียงตามองก์

## 3. ความจริงแปดชั้น (ร่าง)

ชั้นล่างต้องรู้ก่อนจึงเข้าใจชั้นบน · ผู้เล่นรู้ได้หลายทาง ไม่ต้องครบทุกทาง

| # | ความจริง | ใครพูด (และบิดอย่างไร) | ชิ้นอยู่ที่ไหน | เปิดได้ตั้งแต่ |
|---|---|---|---|---|
| K1 | **ม่านมีอยู่จริงและกำลังรั่ว** | ทุกฝ่ายเห็น แต่ตีความต่าง: ศาสนจักร = ทัณฑ์สวรรค์ · หอจดหมายเหตุ = แรงดันพลังงาน · เอลฟ์ = กำแพงอ่อนแรง | บอสสิ่งแปลกปลอมบนทวีป, Corruption/Crimson, คำบรรยายของดรอป | องก์ 0 |
| K2 | **บรรพกาลคือเสาค้ำม่าน** | เอลฟ์พูดตรง (ไม่มีใครเชื่อ) · ศาสนจักรเรียกว่าปีศาจ · หอจดหมายเหตุรู้แต่เงียบ | ป่าเผ่าผู้เหลื่อม, ศาลเจ้า, บทสนทนาเอลฟ์, สิ่งแปลกปลอมชี้ทิศบรรพกาล | องก์ I |
| K3 | **ยุครุ่งโรจน์สูบพลังบรรพกาลจนม่านฉีก** | หอจดหมายเหตุ (ปิดบัง) · ออสทรัม (อ้างเป็นมรดก) | ซากในทะเลทรายเงาฝน, The Wound, จักรกลสงคราม, ห้องสมุดหอจดหมายเหตุ | องก์ I–II |
| K4 | **ศาสนจักรลบประวัติศาสตร์** | ออสทรัมกล่าวหา · ศาสนจักรปฏิเสธ | Sykir (บันทึกที่ถูกเผาไม่หมด), King's Landing (บันทึกราชสำนัก) | องก์ I |
| K5 | **ผู้หลุดมามีมาแล้วหลายคน** | ศาสนจักรเรียก "ผู้ถูกเลือก" คนก่อน (นักบุญ) · ลัทธิเรียก "กุญแจ" | Skeletron ใต้ Dragonstone, จารึกในเมือง, System พูดประโยคซ้ำกับของคนก่อน | ปลายองก์ I |
| K6 | **บรรพกาลบางตัวคือผู้หลุดมาคนก่อน** | ไม่มีฝ่ายไหนพูดตรง · หอจดหมายเหตุสงสัย | ความทรงจำของบรรพกาลที่เคยเป็นคน (ข้อ 5) | องก์ II–III |
| K7 | **The System คือม่าน มันนำผู้หลุดมาไปเป็นกำแพง** | System เองค่อยๆ เผย (ข้อ 6) · เอลฟ์และหอจดหมายเหตุยืนยันบางส่วน | System ผิดปกติ, ความทรงจำที่มี "หน้าต่าง" แบบเดียวกัน | องก์ III |
| K8 | **ทางทำลายวงจร** | ไม่มีใครรู้ครบ ต้องปะติดเอง | ต้องรู้ K1–K7 + เอลฟ์เป็นพันธมิตร | องก์ IV (ตอนจบลับ) |

## 4. เส้นทาง: บอส → ม่านบาง → ที่ใหม่ (ร่าง)

```
ทวีปเปิดทั้งหมดตั้งแต่ต้น (อ่านอันตรายจาก System)
  │  สิ่งแปลกปลอม T0–T2 = หลักฐานรั่ว (K1) · แต่ละตัวชี้ทิศบรรพกาลหนึ่งตัว (K2)
  │  Skeletron ใต้ Dragonstone = ผู้หลุดมาคนล่าสุดที่ไม่สำเร็จ (K5)
  ▼
WoF ผนึกเนื้อ  ── ชั้นที่ 1 บาง ──►  วง I–II เปิด · System ผิดพลาดครั้งแรก
  │  จักรกลสงคราม NE/NW (วง II) = ความจริงของยุครุ่งโรจน์ (K3)
  ▼
จักรกลตัวแรกล้ม ── ชั้นที่ 2 บาง ──►  วง III เปิด (ทุกทิศ)
  │  บรรพกาล T4 ปลายทิศ: ทุกตัวให้ความทรงจำ · บางตัวเคยเป็นคน (K6)
  │  Plantera บนทวีป = บรรพกาลตัวที่เจ็ด จุดเลือกทางศีลธรรม
  ▼
บรรพกาลล้มครบตามเกณฑ์ ── ชั้นสุดท้าย ──►  Ender Guardian (ขอบม่าน, ตะวันออก) → ประตูกลาง Wound
  ▼
ตอนจบ ตามชิ้นความจริงที่ปะติดได้ (ข้อ 7)
```

**ม่านบางให้เห็นด้วยตา:** ขอบวงที่ยังไม่เปิดเป็นหมอกหรือกำแพงม่าน (world border เฉพาะวง หรือ effect + damage) · เมื่อชั้นบาง System ประกาศ
และหมอกถอยออกไปถึงวงถัดไป · ผู้เล่นเห็นว่าตัวเองเป็นคนทำ ซึ่งตรงกับแกน

**ข้อที่ต้องตัดสินต่อ:** "บรรพกาลล้มครบตามเกณฑ์" คือกี่ตัว (ทั้งหก หรือจำนวนหนึ่ง แบบ Great Runes ของ Elden Ring)

## 5. บรรพกาลตัวไหนเคยเป็นคน (ร่างให้ผู้ใช้เลือก)

หลัก: เลือกตัวที่**รูปร่างเป็นมนุษย์หรือสวมเกราะ** และมีเรื่องใน CATACLYSM 4.1 ที่รองรับ แต่ละคนมาจากยุคต่างกัน เรียงแล้วเห็นวงจร

| ยุค (bible 3) | ผู้หลุดมา → บรรพกาล | ทำไม | ความทรงจำที่ได้ (เบาะแส) |
|---|---|---|---|
| ก่อนยุครุ่งโรจน์ | **Scylla** จักรพรรดินีพายุ | รูปร่างมนุษย์ · เอลฟ์บูชาเป็นเทพ = เอลฟ์บูชาอดีตผู้หลุดมาโดยไม่รู้ | เธอเห็นหน้าต่างแบบเดียวกับผู้เล่น และเลือกเป็นกำแพงเพื่อปกป้องคนที่รัก (ตอนจบ "ขึ้นเป็นกำแพง" ในอดีต) |
| มหาสงครามสมอ | **Ignis** อัศวินไฟ | อัศวินในชุดเกราะ · ออรัมสูบความร้อนของเขา | เขาถูกอาณาจักรเก่าใช้เป็นอาวุธ แล้วถูกผนึกตอนหลุดสมอ · ความจริง K3 จากปากคนใน |
| หลังหลุดสมอ ยุคศาสนจักร | **Maledictus** (bible ระบุไว้แล้ว) | อัศวินต้องสาปในคุกน้ำแข็ง Door of Seal | ศาสนจักรขังเขาไว้ก่อนเขาจะสำเร็จ แล้วตั้งปฏิทิน "แสงเดียว" จากคืนที่เขาหายไป (K4 + K5) |
| ปีแสง ~300 | **Skeletron** (บอสทวีป ไม่ใช่บรรพกาล) | bible 5.2 | คนล่าสุดที่ไม่สำเร็จ ออสทรัมขังไว้ใต้บัลลังก์ · เบาะแสแรกของ K5 |

**บรรพกาลแท้ (ไม่เคยเป็นคน):** Ancient Remnant (เก่าที่สุด) · The Leviathan · Ender Guardian (ขอบม่าน) · Plantera (เทพป่า)
**จักรกล** (Harbinger, Monstrosity) ไม่ใช่ทั้งสองแบบ เป็นของที่มนุษย์สร้าง

ผลที่ได้: ผู้เล่นฆ่าเทพของเอลฟ์ (Scylla) แล้วพบว่าเธอเคยเป็นแบบตัวเอง → เอลฟ์ก็ไม่รู้ความจริงครบเหมือนกัน (หลักข้อ 2)

## 8. เมืองในฐานะพยาน (ร่าง)

ทุกเมืองมี **ช่องพยาน** อย่างน้อยหนึ่งช่อง: คน (MCA ที่มีบทพูดพิเศษ) หรือของ (จารึก หนังสือ ซาก) · ใช้ตาราง civic ที่มีอยู่แล้ว (`civic.json`) เพิ่มบทบาท "พยาน"

| เมืองหลวง | ชิ้นใหญ่ที่ถือ | ใครเล่า / บิดอย่างไร |
|---|---|---|
