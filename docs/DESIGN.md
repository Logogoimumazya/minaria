## 1b. หลัก: "The System" — ทุกระบบเป็นหน้าต่างที่ผู้เล่นเปิดดูและกดได้

ผู้ใช้กำหนด 2026-09-26 (สองข้อความ):
1. ระบบที่ทำงานแค่เบื้องหลังหรือพิมพ์ในแชทถือว่ายังไม่เสร็จ ทุกระบบต้องมีหน้าจอให้ดูและให้กด เป็นภาษาอังกฤษ
2. ออกแบบโดยนึกภาพว่าเราเป็นผู้เล่นที่หลุดเข้ามาในเกม RPG แบบการ์ตูน isekai เปิดหน้าต่างดูสถานะ ดูรายละเอียดคนและสถานที่ได้

**ใน lore (bible 6.1):** ผู้มาจากต่างโลกมองเห็นม่านเป็น "หน้าต่าง" คนในโลกนี้มองไม่เห็น หน้าต่างเหล่านี้คือ **The System**
มันบอกสถานะ ประเมินคน แจ้งเตือน และให้ภารกิจ ทุกอย่างที่ผู้เล่นเห็นจึงเป็นส่วนหนึ่งของเรื่อง ไม่ใช่แค่ UI ของเกม
twist ขององก์ III: The System คือม่านเองที่นำทางผู้มาจากต่างโลกทุกคนไปฆ่าบรรพกาล จนสุดท้ายกลายเป็นกำแพงแทน (bible 6.2)

## 2. วงรอบการเล่น (cycleplay): เล่นอย่างไรในแต่ละช่วงเวลา

เกมต้องมีเป้าหมายให้ทำในทุกช่วงเวลา แต่ละช่วงต้องส่งผลไปช่วงที่ยาวกว่า

| ช่วง | ผู้เล่นทำอะไร | ส่งผลต่ออะไร |
|---|---|---|
| **นาที** | ต่อสู้ด้วย Better Combat, สำรวจซากโลกเก่า, หาของ | เงิน, วัตถุดิบ, เบาะแส lore |
| **รอบเล่น (1–2 ชม.)** | รับงานที่บอร์ด → เตรียมตัว (ซื้อ ซ่อม จ้างคน) → เดินทาง → ทำงาน → กลับมาส่งงาน จ่ายภาษี ใช้เงิน | ชื่อเสียงกับฝ่าย/ขุนนาง, ความสัมพันธ์กับคน |
| **องก์ (หลายรอบ)** | ล้มบรรพกาลหนึ่งตัว → โลกเปลี่ยน: ม่านบางลง ศัตรูใหม่ ฝ่ายต่างๆ ขยับ | ปลดระบบ, สงครามระหว่างแคว้น |
| **ทั้งเกม** | เลือกข้าง สะสมพันธมิตร รู้ความจริง เลือกตอนจบ (bible ข้อ 6.3) | ตอนจบ |

**วงรอบของโลกเอง** ทำให้ผู้เล่นไม่ใช่คนเดียวที่ทำให้โลกเปลี่ยน:
- **วัน/คืน:** กลางคืนประตูเมืองปิด (เข้าได้ด้วยสินบนหรือชื่อเสียง) ซอยมืด อาชญากรรมมากขึ้น
- **สัปดาห์เกม:** คาราวานวิ่ง ราคาตลาดขยับ คลังแคว้นเก็บภาษี ขุนนางส่งทหารลาดตระเวน
- **องก์:** แคว้นประกาศสงครามกันเอง ชายแดนเลื่อน หมู่บ้านถูกเผาหรือถูกยึด ผ่าน `confluence_world` realms/wars
  (จุดตั้งต้นคือตาราง bible 4.8 ซึ่งอยู่ในโค้ดแล้ว องก์ II เปลี่ยนคู่ไหนดู `GAMEPLAY.md` ข้อ 6)

## 3. ความสมจริง (immersion): เล่าผ่านโลก ไม่เล่าผ่าน UI

1. **ข้อมูลอยู่ในโลก:**
   - ข่าวอยู่ที่ notice board ประจำแคว้น
   - ทางไปเมืองอยู่ที่ป้ายบอกทางตามทางแยก ระยะคำนวณจริง
   - แผนที่ใช้ Map Atlases ไม่มีหมุดลอย
   - Xaero เปิดเฉพาะพื้นที่ที่ผู้เล่นเคยไป
2. **การเดินทางมีน้ำหนัก:**
   - Waystone มีแค่ในนครและเมือง หมู่บ้านไม่มี
   - ถนนมีคาราวานและด่านเก็บภาษีที่พรมแดน
   - ม้า (SWEM) และเกวียน (AstikorCarts, Trotting Wagons) คือของที่ต้องซื้อ เลี้ยง และดูแล
3. **เมืองมีกฎ:**
   - ค่าผ่านประตู กฎห้ามพกอาวุธในย่านขุนนาง เคอร์ฟิว
   - ทำผิดแล้ว MCA Crime ติดตามจริง
   - ยามจำหน้าได้
4. **คนมีชีวิต:**
   - ชาวบ้าน MCA มีบ้าน มีงาน มีจุดทำงานในอาคารที่ fit-out วางไว้
   - ทหารเดินเวร ขุนนางมีราชสำนัก
   - ชื่อร้านและสำเนียงตามแคว้น
5. **เสียงและแสง:**
   - Sound Physics + AmbientSounds
   - โคมเฉพาะถนนหลัก ซอยมืดจริง
   - โรงหลอมของแคว้นโรงหลอมมีควัน
   - ออสทรัมเงียบและร้าง
6. **lore เป็นเศษเสี้ยว:** คำบรรยายไอเท็ม หนังสือในห้องสมุด จารึกในซาก ไม่มีฉากเล่าเรื่องยาว

## 4. เศรษฐกิจ: ทำอย่างไรไม่ให้เงินง่ายเกินไป

หลัก: **เงินต้องไหลออกเร็วเท่าที่ไหลเข้า** และแหล่งเงินทุกแหล่งต้องมีเพดานหรือต้นทุน

**ทางเข้าของเงิน (faucet) พร้อมเพดาน:**

| ทาง | เพดาน / ต้นทุน |
|---|---|
| งานบนบอร์ด (Bountiful) | จำนวนงานต่อวันต่อบอร์ดจำกัด ค่าตอบแทนตามองก์ |
| ค่าหัวบอส (สมาคมนักล่า) | จ่ายครั้งเดียวต่อบอสต่อโลก |
| ขายของให้พ่อค้า | **ราคาตกเมื่อขายของชนิดเดิมซ้ำ** (ตลาดอิ่ม) ฟื้นตัวทีละสัปดาห์เกม · หักภาษีตลาดตามแคว้น |
| เหรียญจากมอนสเตอร์ (Confluence) | ลดลงใกล้ spawner และในฟาร์มม็อบ (นับจำนวนฆ่าต่อพื้นที่ต่อชั่วโมง) |
| ของในซาก (Lootr) | ครั้งเดียวต่อผู้เล่นต่อหีบ |
| การค้าคาราวาน | ซื้อถูกที่แหล่งผลิต ขายแพงที่ปลายทาง มีความเสี่ยงโจรบนถนน |

**ทางออกของเงิน (sink):**

| ทาง | ทำไมผู้เล่นยอมจ่าย |
|---|---|
| ค่าผ่านประตู, ภาษีตลาด | เข้าเมืองและค้าขายได้ |
| ซ่อมอาวุธ/เกราะ (ความทนทานสำคัญ) | ของดีพังเร็ว |
| ค่าเช่าห้องที่โรงเตี๊ยม / ซื้อบ้านในเมือง | จุดเกิดใหม่และที่เก็บของปลอดภัย |
| ค่าเลี้ยงดูม้า ทหารรับจ้าง ผู้ติดตาม (รายสัปดาห์) | กำลังรบและการเดินทาง |
| สินบน ค่าปรับ ค่าไถ่ตัวจากคุก | ทางลัดเมื่อทำผิด |
| ค่าสมาชิกกิลด์ ค่าเรียนเวท ค่าใบอนุญาต Create (หอจดหมายเหตุ) | ปลดความสามารถ |
| ของบริจาคให้ศาสนจักร | ชื่อเสียง |

**ราคาไล่ตามองก์:**
- ขององก์ 0 ราคาเป็นทองแดงถึงเงิน องก์ II ขึ้นไปเป็นทอง (bible ข้อ 9)
- ขององก์ถัดไปจะไม่ขายก่อนถึงองก์นั้น แม้มีเงิน ต้องมีชื่อเสียงหรือเควสประกอบ

**เสาหลัก "ทุกพลังมีราคา":** ของแรงที่สุดซื้อด้วยเงินไม่ได้ ต้องจ่ายด้วยชื่อเสียง ร่างกาย หรือศรัทธา

## 5. คนและความสัมพันธ์: ห้าชั้นที่เชื่อมกัน

| ชั้น | ระบบ | ตัวอย่างผลที่ข้ามไปชั้นอื่น |
|---|---|---|
| **ฝ่ายโลก 5 ฝ่าย** (ศาสนจักร หอจดหมายเหตุ เอลฟ์ ลัทธิ นักล่า) | `minaria_factions.js` | ศาสนจักรเกลียด → ภาษีในรัฐศาสนจักรสองเท่า และนักบวชในเมืองไม่รักษา |
| **แคว้น/ขุนนางท้องถิ่น** | `/standing` ใน `confluence_world` | standing สูง → ผ่านประตูฟรี ได้ที่ดิน ได้บรรดาศักดิ์ · ต่ำ → ถูกไล่ล่า |
| **ราชสำนัก** (ขุนนางและทหารเป็นคน MCA) | `minaria_court` | ช่วยขุนนาง → ได้สั่งทหาร ลดภาษี แต่งงานเข้าตระกูล |
| **คนรายบุคคล** | MCA (หัวใจ ครอบครัว) | เพื่อนในเมืองให้ข่าว ส่วนลด ที่หลบภัย · คู่ครองผูกผู้เล่นกับบ้านนั้น |
| **กฎหมาย** | MCA Crime / Reputation | อาชญากรรม → ค่าหัว ยามไล่จับ และ standing กับขุนนางลด |

**หลักเชื่อม:** การกระทำหนึ่งครั้งต้องเห็นผลอย่างน้อยสองชั้น เช่น ฆ่าเอลฟ์ให้ศาสนจักร
- ศาสนจักร +
- เอลฟ์ −− (บุกหมู่บ้านชายป่า)
- ขุนนางที่ค้ากับเอลฟ์ −

**ที่ต้องทำต่อ:** บทลงโทษของทุกฝ่าย (ตอนนี้เป็นแค่ข้อความ) และหน้าจอชื่อเสียงในเกม (ตอนนี้อยู่ในแชท)

## 6. ออกแบบโลก: เมืองยังซ้ำ แก้อย่างไร

**ปัญหาที่วัดได้จากโค้ดตอนนี้:**
- ทุกเมืองใช้วงแหวนรูปไข่ มีลานตรงกลาง และถนนแผ่เป็นรัศมี
- ต่างกันแค่ขนาดกับสีตามแคว้น
- 29 เมืองท่าไม่มีท่าเรือเลย
- ไม่มีเมืองไหนมีปราสาทหรือป้อมของขุนนาง ยกเว้นเมืองที่วางจากงานคนอื่น (KL, Casterly Rock, Dragonstone)

### 6.1 รูปทรงตามทำเล (ไม่ใช่วงแหวนแบบเดียว)

| ทำเล | ผัง | ตัวอย่างจริง |
|---|---|---|
| ที่ราบ | ผังตาราง ลานสี่เหลี่ยม (bastide) | เมืองใหม่ของวาลาเรีย |
| เนิน/เขา | ถนนเลียบเส้นชั้นความสูง เป็นขั้นบันได ป้อมบนยอด | Lutesk, เมืองแคว้นโรงหลอม |
| ริมแม่น้ำ | แม่น้ำผ่ากลางเมือง มีสะพานหลักและท่าน้ำ | Rattay (Kingdom Come) |
| ชายฝั่ง | ผังโค้งตามอ่าว ถนนลงท่าเรือ กำแพงทะเล | Liro, Sykir |
| ทางแยก | เมืองยาวตามถนน (street village) ไม่มีกำแพง | หมู่บ้านบนเส้นคาราวาน |
| รอบปราสาท | บ้านเกาะรอบกำแพงปราสาท (castle town) | เมืองของขุนนางชายแดน |

**ทำได้โดย:** `town.plan` รับ "ชนิดผัง" จากการวิเคราะห์ทำเลตอน `settlements.py plan`
- วัดความชัน แม่น้ำ ชายฝั่ง และถนนผ่าน แล้วเลือกผังให้เหมาะ
- ลานไม่ต้องอยู่ตรงกลางเสมอ ให้อยู่ที่ทางแยก ริมท่า หรือหน้าประตูปราสาท

### 6.2 หน้าที่หลักของเมือง (ความเชี่ยวชาญ)

เมืองละหนึ่งหน้าที่หลักจากภูมิประเทศ (แนวคิด Total War) หน้าที่กำหนดย่าน อาคาร ชนบท และของขายในตลาด

| หน้าที่ | มาจาก | สิ่งที่เพิ่ม |
|---|---|---|
| ท่าเรือ | ติดทะเล | ท่า คลังสินค้า ร้านปลา อู่ต่อเรือ ประภาคาร |
| เหมือง/โรงหลอม | ภูเขา | ปากเหมือง ลานหิน เตาถลุง กองถ่าน |
| ตลาดเกษตร | ที่ราบ | ยุ้งฉาง โรงสี ลานสัตว์ |
| ทางผ่าน/การค้า | ทางแยกถนนใหญ่ | โรงเตี๊ยมหลายหลัง คอกม้า ลานคาราวาน |
| ป้อมชายแดน | ใกล้พรมแดนแคว้น | โรงทหารใหญ่ ด่านภาษี ลานฝึก |
| ศาสนา/แสวงบุญ | รัฐศาสนจักร | มหาวิหาร ที่พักผู้แสวงบุญ |
| ป่าไม้ | ป่า | โรงเลื่อย กองซุง |

### 6.3 เมืองชายฝั่งกับน้ำ

- **ท่าเรือ:** ขุดแอ่งท่าให้ลึกพอ มีกำแพงท่า (quay) สะพานไม้ยื่น (Nifty Ships `cleat`) โกดังริมท่า และเขื่อนกันคลื่นในอ่าวเปิด
- **ประตูน้ำ (water gate):** ช่วงกำแพงที่แม่น้ำผ่าน มีซุ้มโค้งและลูกกรงเหล็ก แม่น้ำจึงไหลออกทะเลผ่านเมืองได้ ไม่ถูกกำแพงตัด
- **ริมน้ำในเมือง:** เขื่อนหินสองฝั่ง ท่าน้ำขั้นบันได สะพานหลายแบบ (หิน ไม้ สะพานบ้าน)
- **ท้ายน้ำ:** โรงฟอกหนังและโรงย้อมนอกกำแพงท้ายน้ำ (มีกฎนี้แล้วใน catalogue แต่ยังไม่ได้วางตามแม่น้ำจริง)

### 6.4 ปราสาทและป้อมขุนนาง

| ขนาด | สิ่งที่มี | แหล่ง |
|---|---|---|
| นครหลวง | ปราสาทใหญ่หรือป้อมปราการในเมือง | ปราสาท Valarian (72×40×80) หรือชิ้น KL ใหญ่ |
| นคร | keep หรือหอคอยขุนนางบนจุดสูงสุด มีกำแพงชั้นใน | ออกแบบเป็นชิ้นใหม่ |
| เมือง | บ้านป้อม (tower house) หรือคฤหาสน์มีกำแพง | ชิ้น KL rich + กำแพงรอบ |
| หมู่บ้าน | ไม่มี ขึ้นกับปราสาทใกล้ที่สุด (Mount & Blade) | – |
| พรมแดน | ป้อมเล็กตรงถนนข้ามแดน มีด่านภาษี | ป้อม Valarian |

แต่ละแคว้นมีรูปแบบของตัวเอง
- **ศาสนจักร:** มหาวิหารแทนปราสาท
- **ออรัม:** หอธนาคาร
- **แดนเสรี:** ป้อมโจรสลัด
- **ออสทรัม:** ปราสาทพังครึ่งหลัง

### 6.5 ความลาดของเมือง

- ตอนนี้วางอาคารบนฐานสูงได้ไม่เกิน 4–5 บล็อก และถนนไต่ได้ทีละบล็อก
- **ที่ขาด:** เมืองบนเขาต้องเป็น**ขั้นลาน (terrace)** มีกำแพงกันดิน บันไดหินเชื่อมขั้น และถนนเลียบเส้นชั้นความสูง ไม่ใช่เนินลื่นๆ
- กำแพงเมืองบนไหล่เขาต้องมีลาดหิน (glacis) ใต้ฐาน ไม่ใช่ก้อนหินเหลี่ยม

### 6.6 ของตกแต่งที่ยังขาด

| กลุ่ม | ที่ขาด |

| ความต่างของแคว้น | ความเสื่อมของออสทรัม (บ้านร้าง หลังคาพัง), ควันโรงหลอม, ธงผู้แสวงบุญ |

## 7. ออกแบบสภาพแวดล้อม

- **ระดับความอันตรายตามระยะ:** ใจกลางทวีปปลอดภัยที่สุด ยิ่งใกล้ Wound และดินแดนสะท้อน (นอกทวีป) ยิ่งอันตราย ของดีขึ้น
  - ต้องผูกกับการเกิดของมอนสเตอร์และ loot (bible ข้อ 9)
- **ความเสื่อมใกล้ Wound:** ชนบทออสทรัมรกร้าง ต้นไม้ตาย พืชผิดรูป เป็นรอยต่อทางสายตากับวาลาเรียที่สมบูรณ์
- **สภาพอากาศ:** Simple Clouds ให้พายุจริง เมื่อฝนตกหนัก คาราวานหยุด ท่าเรือปิด
- **เสียง:** แต่ละแคว้นมีโทนเสียงเฉพาะ เช่น ระฆังโบสถ์ในรัฐศาสนจักร ค้อนในแคว้นโรงหลอม และทะเลในออรัม
- **นอกทวีป:** worldgen อัตโนมัติไปเรื่อยๆ ไม่มีเมืองของเรา จนกว่าจะทำ mod `minaria_world` (`GAME_SYSTEMS.md` ข้อ 3)
