# Minaria Blueprint — วิธีทำงาน ที่อยู่ของแต่ละชิ้น และรูปร่างของเกมทั้งเกม

เขียน 2026-09-26 หลังสัมภาษณ์ผู้ใช้สามรอบ เอกสารนี้ตอบสองเรื่อง
1. **เราทำงานกันอย่างไร** และระบบใหม่ต้องเขียนไว้ที่ไหน จะได้ไม่ต้องทำซ้ำตอนแยกเป็นม้อด
2. **เกมทั้งเกมมีรูปร่างอย่างไร** ตั้งแต่ทวีปจนถึงดินแดนสะท้อน ออกแบบส่วนนอกไว้ตอนนี้เพื่อให้ระบบบนทวีปรองรับได้ตั้งแต่แรก

**งานตอนนี้ยังอยู่บนทวีป** (ข้อ 4) ดินแดนสะท้อน (ข้อ 6) เป็นเฟสหลัง ระบุไว้ตรงนี้แค่ให้ระบบบนทวีปใช้ต่อได้
หน้าภาพของเอกสารนี้: artifact "Minaria Blueprint" · รายละเอียดการแจก: [`PRODUCT_PLAN.md`](PRODUCT_PLAN.md)

## 3. กฎที่อยู่ของโค้ด — กันงานซ้ำ

ต้นเหตุที่จะทำให้งานซ้ำคือเขียนระบบใน KubeJS ก่อน แล้วต้องเขียนใหม่เป็น Java ตอนแยกม้อด จึงใช้กฎนี้ตั้งแต่วันนี้

| ถ้าสิ่งที่ทำคือ | เขียนที่ | ตัวอย่าง |
|---|---|---|
| ชื่อ ตัวเลข สถานที่ ข้อความ | **ไฟล์ข้อมูล** เท่านั้น ไม่ฝังในโค้ด | ราคา ภาษี รายชื่อบอส พิกัดเมือง |
| logic ที่จะอยู่ในม้อดแยก (ตาราง 3.1) | **Java ในม้อดนั้นเลย** | หน้าต่างใหม่, ระบบวงระยะ, ภาษีบนหน้าซื้อขาย |
| ของเฉพาะแพ็กนี้ | KubeJS | สูตรคราฟต์ บาลานซ์ การผูกเควส สคริปต์ทดสอบ |
| บล็อกของโลก | Python ออฟไลน์ | เมือง ถนน เขตบอส |

**ระบบเดิมใน KubeJS:** แช่แข็ง ไม่เพิ่มฟีเจอร์ใหม่ในไฟล์เดิม ย้ายไป Java ทีละม้อดตามลำดับข้อ 5 ระหว่างย้าย ตัว KubeJS ยังทำงานจนตัว Java ผ่านเทสต์ชุดเดียวกัน แล้วค่อยลบ

| เล่นองก์ 0–I ครบรอบ | G10 | — | วัดเวลาและจุดที่น่าเบื่อ |

**สิ่งที่ระบบบนทวีปต้องรองรับตั้งแต่ตอนนี้** เพื่อให้ Echoes ไม่ต้องรื้อ:
- NOTICE มีรูปแบบ "เข้าพื้นที่" ที่ใส่ความลึกและระดับอันตรายได้ (ใช้ตัวเดียวกับ "Entered")
- Realm map วาดนอกกรอบทวีปได้ (วงและทิศที่สำรวจแล้ว)
- ทะเบียนบอสมีช่อง `tier`, `bearing`, `depth` ตั้งแต่แรก
- จุดเกิดใหม่และการเดินทางใช้ Waystones ชุดเดียวกันทั้งในและนอกทวีป
- ชุดชิ้นส่วนเมือง (GAME_SYSTEMS ข้อ 3 เป้าหมายที่ 1) ทำเป็น structure ที่ใช้กับเมืองสะท้อนได้

## 6. ดินแดนสะท้อน — กติกาที่ทำให้สุ่มแต่อ่านออก (เฟสหลัง)

1. **ระยะ = ความลึก** วัดจากขอบทวีปที่ใกล้ที่สุด
   | วง | ระยะจากขอบ | องก์ | อะไรอยู่ที่นั่น |
   |---|---|---|---|
   | ชายม่าน | 0–512 | 0 | เมืองสะท้อนที่ตื่น ปลอดภัย |
   | วง I | 512–2,000 | II | เมืองสะท้อน มอน ×1.5 |
   | วง II | 2,000–4,000 | II | ประตูจักรกล (ปลายทิศ NE, NW) มอน ×2.5 |
   | วง III | 4,000–6,000 | III–IV | ประตูบรรพกาล (ปลายทิศอื่น) มอน ×4 |
   | กำแพงม่าน | 6,500 | — | world border (ทวีป ±8192 + 6,500) |
2. **ทิศ = ธาตุ** แบ่ง 8 ทิศ ทิศละ 45° จากกลางทวีป แต่ละทิศมีไบโอม มอน มินิบอส เมืองสะท้อน และห้องของตัวเอง ต่อจากภูมิศาสตร์ของทวีปฝั่งนั้น
   | ทิศ | ต่อจาก | ห้อง (Cataclysm Dimension) | เจ้าของ |
   |---|---|---|---|
   | เหนือ | หิมะวาลาเรีย | Eternal Frosthold | Maledictus (ผู้มาจากต่างโลกคนก่อน) |
   | ตะวันออกเฉียงเหนือ | สนามรบของ Wound | Forge of Aeons | The Harbinger (จักรกล) |
   | ตะวันออก | สะพานแผ่นดิน (ทางที่ผู้เล่นหลุดมา) | Bastion of the Lost | Ender Guardian (ขอบม่าน องก์ IV) |
   | ตะวันออกเฉียงใต้ | ทะเลอุ่นหลัง Moueiras | Sanctum Fallen | Scylla |
   | ใต้ | ภูเขาไฟ Liria และโรงหลอม Rzhia | Inferno's Maw | Ignis |
   | ตะวันตกเฉียงใต้ | ทะเลทรายเงาฝน | Pharaoh's Bane | Ancient Remnant |
   | ตะวันตก | ทะเลของศาสนจักร | Abyssal Depths | The Leviathan |
   | ตะวันตกเฉียงเหนือ | ป่าเถ้าหลังเขาวาลาเรีย | Soulforge Anvil | Netherite Monstrosity (จักรกล) |
3. **เสียงสะท้อนทำซ้ำ** เมืองสะท้อนใช้ชุดชิ้นส่วนเมืองของเรา คนในนั้นหน้าและชื่อซ้ำกับคนบนทวีป (ทำทีหลัง)

## 9. แจกทวีปผ่าน CurseForge (ตัดสินแล้ว: โลกบีบอัด + ปุ่มสร้างโลก)

**ตัวเลขที่วัดแล้ว (2026-09-26):**
- เซฟ "Minaria Continent": region 4.7 GB (1,052 ไฟล์), DH 196 MB (สร้างใหม่ได้ ไม่ต้องแจก), roadweaver 19 MB
- CurseForge: ไฟล์ละไม่เกิน 2 GB และต้องเป็น .zip ([support.curseforge.com](https://support.curseforge.com/support/solutions/articles/9000197241-creating-and-submitting-a-project))
- zip ตรงๆ ประมาณ 2.6 GB: ข้อมูลใน region บีบด้วย zlib มาแล้ว zip ช่วยได้แค่ส่วนที่เว้นว่าง จึงเกิน
- ตัดแสง (SkyLight/BlockLight) กับ heightmap ที่เกมคำนวณใหม่เองแล้วบีบ xz: r.0.0 จาก 5.7 MB เหลือ 1.63 MB (29%) → ทั้งทวีปประมาณ **1.3–1.5 GB**
  บล็อก ของตกแต่ง entity ครบทุกก้อน (ตัวเลขทั้งทวีปเป็นค่าประมาณจาก region ตัวอย่าง ต้องวัดจริงตอนบีบ)

**ผู้เล่นเห็นอะไร:**
1. กด Install แพ็ก Minaria ใน CurseForge
2. เปิดเกม หน้า System มีปุ่ม **New Journey**
3. ครั้งแรกม้อด atlas แตกไฟล์ทวีปเป็นเซฟใหม่ (ประมาณ 2–5 นาที มีแถบความคืบหน้า) แล้วเข้าเกมที่ชายม่านเลย
4. ครั้งต่อไปกดเซฟเดิมตามปกติ ไฟล์บีบเก็บไว้เพื่อเริ่มใหม่ได้

**ไฟล์ทวีปอยู่ที่ไหน (ต้องทดสอบตามลำดับนี้):**
1. โปรเจกต์แยกบน CurseForge ที่แพ็กอ้างใน manifest → อัปเดตแพ็กไม่ต้องโหลดโลกใหม่ ต้องทดสอบว่าแอปติดตั้งไฟล์ชนิดนี้ให้เองไหม
2. ถ้าไม่ได้: ใส่ไว้ใน overrides ของแพ็ก (แพ็กรวม ~1.5 GB ยังต่ำกว่า 2 GB) ข้อเสียคืออัปเดตแพ็กแต่ละครั้งต้องโหลดใหม่ทั้งก้อน
3. ไม่ใช้เว็บนอก CurseForge (การโหลดจากเว็บนอกเป็นสัญญาณอันตรายในการตรวจของ CurseForge)

**เครื่องมือ:** `dev/worldgen/pack_continent.py` (ใหม่) อ่านเซฟ ตัดแสงและ heightmap ตั้ง `isLightOn=0` บีบทีละ region
atlas อ่านกลับแล้วเขียน .mca ปกติ เกมคำนวณแสงเองตอนโหลด chunk ครั้งแรก
