## ระบบหลัก

- **หอดารา (หน้าแรก):** ดวงจันทร์คืนนี้คำนวณจากรอบเดือนจันทรคติเฉลี่ย 29.53 วัน บอกข้างขึ้น/แรมกี่ค่ำ และดวงจันทร์ 7 วันข้างหน้า · ไพ่ประจำวันต้องกดค้างจนวงแสงเต็มถึงจะเปิด วันเดียวกันได้ใบเดิม (seed จากวันที่ + วันเกิด หรือ seed ของเครื่องถ้าไม่ใส่วันเกิด) มีพลังของวันที่ปรับตามดวงจันทร์ สิ่งที่ควรใช้ สิ่งที่ควรระวัง และคำถามติดตัว · นับวันที่เปิดต่อเนื่อง
- **สมุดดวง:** เก็บคำทำนายได้ 200 รายการ ครบ 7 วันจะขึ้นป้าย "ถึงเวลาทบทวน" ผู้ใช้เลือก ตรง/ตรงบางส่วน/ไม่ตรง แล้วเล่าสิ่งที่เกิดขึ้น ให้ Claude สะท้อนบทเรียน (ถ้าไม่มี Claude จะใช้ตำราของหอดารา) · รูปแบบที่วนกลับมา: ไพ่ที่ออกซ้ำ ธาตุเด่นใน 30 วัน เรื่องที่ถามซ้ำ · ปฏิทินไพ่ประจำวัน 28 วัน · สำรองหรือนำเข้าเป็นไฟล์ JSON
- **คลังไพ่:** ไพ่ 78 ใบ กรองตามชุดหรือค้นหาได้ แต่ละใบบอกความหมายตั้งตรง/กลับหัว ตัวอย่าง ธาตุ และดาว/ราศีประจำไพ่ (ตามระบบ decan) · ควิซ 4 แบบ ได้ XP และเลื่อนยศ 6 ขั้น ใบที่ตอบผิดบ่อยจะถูกถามบ่อยขึ้น
- **ไพ่ประจำตัวและดวงคู่:** ไพ่ประจำตัว ไพ่ประจำวิญญาณ ไพ่ประจำปี และเลขเส้นทางชีวิต · ดวงคู่รวมไพ่ประจำตัวสองคนเป็นไพ่ของความสัมพันธ์ ดูธาตุเสริม/ต้าน และกลุ่มเลขเส้นทางชีวิต แยกคำแนะนำตามประเภทความสัมพันธ์ ให้ Claude เล่าแบบละเอียดเพิ่มได้
- **เสียงและการแชร์:** ดนตรีสังเคราะห์ด้วย WebAudio เปลี่ยนคอร์ดตามห้องและธาตุของคำทำนาย และมีเสียงฆ้องตอนเปิดไพ่เงา · การ์ด PNG ขนาด 1080×1920 บันทึกผ่าน capability `downloads` หรือปุ่มแชร์ของเครื่อง
- **สับไพ่**: riffle แบบ Gilbert–Shannon–Reeds (สุ่มด้วย `crypto.getRandomValues`) ทุกครั้งมีโอกาส 50% ที่กองหนึ่งจะถูกหมุน 180° → เกิดไพ่กลับหัวตามธรรมชาติ
  มาตรวัดความสุ่มคำนวณ total variation distance ตาม Bayer–Diaconis (1992): ไพ่ 78 ใบต้องสับราว 10 ครั้งจึงจะสุ่มจริง (52 ใบ = 7 ครั้ง)
- **ตัดไพ่** 3 กอง ผู้ใช้เลือกกองขึ้นบน → **กางพัด 78 ใบ** ให้จิ้มเลือกเอง (ใบที่เลือก = ใบจริงในลำดับที่สับแล้ว)
- **รูปแบบการวาง**: ไพ่ประจำวัน 1 · อดีต/ปัจจุบัน/อนาคต 3 · เส้นทางหัวใจ 5 · งานและการเงิน 5 · กางเขนเซลติก 10
- **คะแนนดวง** 5 ด้าน (รัก งาน เงิน สุขภาพ โชค): ค่าพลังไพ่ (−3..+3, กลับหัวมีค่าแยก) × ความสัมพันธ์ของชุด/ไพ่กับด้านนั้น × น้ำหนักตำแหน่ง × 1.3 ถ้าเป็นชุดใหญ่ → `50 + 48·tanh(...)`
- **เลขศาสตร์**: เลขเส้นทางชีวิต (เก็บเลขมาสเตอร์ 11/22/33), ไพ่ประจำตัวและไพ่ประจำปีตามวิธี Mary K. Greer, เลขชื่อ (ไทยตามตำราเลขศาสตร์ / อังกฤษแบบพีทาโกรัส), สีและดาวประจำวันเกิดแบบไทย
- **ภาพไพ่** วาดด้วย SVG ทั้งหมด: ชุดใหญ่ใช้สัญลักษณ์โหราศาสตร์ตาม Golden Dawn + สามเหลี่ยมธาตุ, ชุดเล็กวาง pip ตามจำนวน, ลายหลังไพ่สมมาตร 180° จึงดูไม่ออกว่าใบไหนกลับหัว
- ประวัติการเปิดไพ่ 12 ครั้งล่าสุดเก็บใน `localStorage` ของเครื่องผู้ใช้เท่านั้น
- **สรุปแบบเข้าใจง่าย**: บทสรุปที่ร้อยทุกตำแหน่งเป็นเรื่องเดียว (ประโยคต่อตำแหน่งใน `STORY`), สิ่งที่ควรทำ/ควรเลี่ยงอย่างละ 3 ข้อ, และเหตุผลของคะแนนแต่ละด้าน (ไพ่ใบไหนดันขึ้น/ดึงลง)
- **หมอดูเล่าทีละใบ**: แผงด้านล่างที่เดินเรื่องบนโต๊ะไพ่ ไพ่ใบที่กำลังเล่าจะเรืองแสง ใบอื่นจางลง แต่ละใบอธิบายช่องนี้ถามอะไร ไพ่คืออะไร ภาพบนไพ่ ตั้งตรง/กลับหัว ความหมาย ตัวอย่างชีวิตจริง และผลต่อคะแนน จบด้วยเรื่องรวม เหตุผลคะแนน และสิ่งที่ควรทำ ใช้ปุ่มลูกศรซ้าย/ขวาได้
- **ศัพท์**: คำที่มีเส้นประใต้ (`GLOSS`) แตะแล้วคำอธิบายจะโผล่ใต้บรรทัดนั้น
- **อ่านคำถาม** (`analyzeQ`): หาว่าถามเรื่องใคร (แฟน หัวหน้า แม่ เขา ฯลฯ ถ้าคำว่า ฉัน/เรา มาก่อนถือว่าถามเรื่องตัวเอง), หมวด (รัก งาน เงิน สุขภาพ เรียน ครอบครัว) และแบบคำถาม (ใช่หรือไม่ / เมื่อไหร่ / เลือกสองทาง / ใจเขา / ขอคำแนะนำ / ภาพรวม) แล้วแนะนำการวางไพ่ที่ตอบได้ตรงที่สุด ช่องที่ผู้ใช้แก้เองจะไม่ถูกเขียนทับ
- **ตำแหน่งรู้ว่าพูดถึงใคร** (`ab` ใน `SPREADS`): ใบที่พูดถึงคนอื่นจะเปลี่ยนคำว่า "คุณ" ในคำแปลเป็นชื่อคนนั้น (`voice`) ส่วนคำแนะนำยังพูดกับผู้ถามเสมอ
- **คำตอบของคำถาม** (`answerFor`): ใช่หรือไม่ → ใช่ / ใช่แต่มีเงื่อนไข / ก้ำกึ่ง / ยังไม่ใช่ / ไม่ พร้อมความชัดเจนและไพ่ที่ชี้ขาด · เมื่อไหร่ → อ่านความเร็วจากชุดไพ่ (ไม้เท้าเร็ว ดาบเป็นสัปดาห์ ถ้วยเป็นเดือน เหรียญหลายเดือน กลับหัวช้าลง) หรือเดือนที่เด่นที่สุดในแบบ 12 เดือน · เลือกสองทาง → คะแนนแต่ละทาง · ใจเขา → ระดับความรู้สึกและสิ่งที่เขาจะทำ · ทุกการ์ดมีบรรทัด "เทียบกับคำถาม"
- **Motion** (`Ptr`, `Grade`, `Neb`, `Cam`, `Director`):
  - พื้นหลังเป็น fragment shader (fbm noise แบบ domain warp) เรนเดอร์ครึ่งความละเอียด ลดความละเอียดเองถ้าเครื่องช้า ถ้าไม่มี WebGL จะใช้พื้นหลัง CSS เดิม · ดาว 3 ชั้นความลึกขยับสวนเมาส์
  - เกรดสีตามขั้น: ตั้งจิต=คราม · สับ=ม่วงเข้ม · เลือก=มืดลึกลับ · เปิด=ทอง · คำทำนาย=อุ่น (สีเนบิวลา ฟิล์มสี vignette และไฟหลัก `keylight` เลื่อนตำแหน่งตามขั้น)
  - กล้อง: สับ = มุมสูงลงสู่โต๊ะ, สับต่อเนื่องเป็นโคลสอัพมีแถบดำจอหนังและกล้องสั่นเบาๆ, ตัดไพ่ = ก้มมอง แล้วพุ่งไปที่กองที่เลือก, เลือกไพ่ = แพนกวาดตามพัดที่กางออก, เปิดไพ่ = ซูมเข้าไพ่ทีละใบพร้อมเบลอฉากหลัง (ระยะชัดตื้น) แล้วถอยออก, เปิดทั้งหมด = กล้องกระโดดใบต่อใบ ปิดท้ายด้วยช็อตถอยกว้าง
  - เปิดไพ่: ฉากเปลี่ยนเป็นสีธาตุ (ไฟส้ม น้ำฟ้า ลมเงิน ดินเขียว) วงคลื่นแสง และไพ่ชุดใหญ่มีลำแสงหมุน
  - เปลี่ยนขั้นด้วยการ dip to black · ผู้ใช้ที่ตั้ง reduced motion จะไม่มีการเคลื่อนกล้อง หางแสง หรือการเอียง
- **บทพยากรณ์** (`Oracle`, `Chron`): หน้าเว็บส่งไพ่ ตำแหน่ง คำถามที่วิเคราะห์แล้ว คะแนน และผลวิเคราะห์เชิงลึกให้ Claude ผ่าน capability `sample` ให้เขียนเป็น 6 บท (คำตอบ · เส้นทางผ่านไพ่ · ไพ่สนทนากัน · ไพ่เงา · คำแนะนำ · ลำนำปิดท้าย) ไหลออกมาทีละบท ไพ่ที่บทนั้นพูดถึงเรืองแสงบนโต๊ะ ถ้าใช้ Claude ไม่ได้ (เปิดนอก claude.ai, ไม่อนุญาต, ไม่ว่าง) จะใช้ `houseChronicle` ที่สุ่มสำนวนจากรหัสพิธีให้ไม่ซ้ำ แล้วเล่นออกมาแบบเดียวกัน · คำทำนายที่เขียนแล้วเก็บไว้ในประวัติ เปิดซ้ำไม่ต้องเขียนใหม่
- **ถามหมอต่อ** (`Chat`): ถามต่อได้โดย Claude ตอบจากไพ่ชุดเดิม มีคำถามแนะนำ 3 ข้อที่ Claude เสนอ
- **วิเคราะห์เชิงลึก**: ธาตุหนุน/ต้าน (Golden Dawn elemental dignities) ของไพ่ที่วางใกล้กัน ปรับพลังไพ่ ±45% ก่อนคิดคะแนน · คอมโบไพ่ 23 คู่ + กฎทั่วไป (เลขซ้ำ ไพ่ชุดใหญ่เลขติดกัน ราชา+ราชินี เอซ+สิบ) · เส้นแนวโน้มสำหรับแบบที่มีเส้นเวลา · ตำแหน่งบนเส้นทางไพ่ชุดใหญ่ 3 องก์ · ไพ่เงา = ใบล่างสุดของสำรับหลังเลือกไพ่ เปิดหลังไพ่ครบพร้อมฉากมืดและควัน
- **มุมจิตวิทยา** (`ARCHETYPE`, `SUIT_FUNC`, `psyche`): Major Arcana แต่ละใบผูกกับต้นแบบ (archetype) ของยุง ชุดไพ่ผูกกับฟังก์ชันทางจิตทั้งสี่ (Wands = intuition, Cups = feeling, Swords = thinking, Pentacles = sensation) ไพ่รูปคน = persona ไพ่เงา = shadow · ธาตุต้านอ่านเป็นความขัดแย้งในใจ (`INNER`) · ส่งให้ Claude ในช่อง `psyche` และใช้ในตำราสำรอง โหมดเล่าทีละใบ และหน้าต่างรายละเอียดไพ่
- บทของบทพยากรณ์: คำตอบ · เส้นทางของใจ · แรงที่ทำงานอยู่ข้างใน · เงาของคุณ · สิ่งที่อยู่ในมือคุณ · ลำนำปิดท้าย
